# Жизненный цикл фонового сервиса Codex Remote

`codex remote-control start` запускает фоновый процесс `app-server-daemon`, который связывается с серверами OpenAI и слушает локальный Unix-сокет:
`~/.codex/app-server-control/app-server-control.sock`

## Сравнение типов остановок:

| Действие | Влияние на Remote Daemon | Влияние на интерактивный CLI | Влияние на Termux |
| :--- | :---: | :---: | :---: |
| **Закрыть окно Termux** | ⚠️ Демон может продолжить жить | Завершается | Приложение может быть выгружено |
| **`codex remote-control stop`** | 🟢 Демон штатно останавливается | Не трогает другие процессы | Termux продолжает работу |
| **Виджет `codex-off.sh`** | 🟢 Демон и процессы Codex завершаются | 🟢 Полный чистый сброс | Termux продолжает работу |
| **`kill-all.sh`** | 🔴 Всё принудительно убивается | 🔴 Принудительно убивается | Termux полностью закрывается |

## Удаление зависшего (Stale) PID:
Если процесс аварийно завершился, в `~/.codex/app-server-daemon/app-server.pid` может остаться старый ID. Скрипты `codex-on.sh` и `codex-off.sh` автоматически валидируют PID перед запуском.
